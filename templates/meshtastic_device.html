Meshtastic Device

This BBS is connected to the Meshtastic radio via a serial (USB) port. The device web UI is served from the radio itself and cannot be embedded here because this node accesses it over a direct USB connection, not over TCP/IP.

To access the device web UI

  1. Plug the Meshtastic radio directly into a computer with a web browser (USB cable).
  2. Open client.meshtastic.org in a Chrome or Edge browser (requires WebSerial support).
  3. Click + New device and select the serial port for your radio.

Alternatively, you can switch to TCP mode by setting type = tcp and hostname = <device-ip> in the [interface] section of your config.ini. In TCP mode, the device web UI will be embedded directly on this page.
