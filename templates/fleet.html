Set up fleet signing

  1. On the admin machine, from this repository, run python scripts/fleet_sign.py --group {{ fleet.group or 'baconbbs' }} init. It creates the private key in the correct protected user directory for Windows, Linux, or macOS. No downloaded file needs to be moved.
  2. Keep an offline backup of the path printed by init.
  3. On each node, paste the public entry printed by init under Trust a new key, or run python scripts/fleet_sign.py --group {{ fleet.group or 'baconbbs' }} enroll 'fk...:...' in that node's repository.
  4. Run python scripts/fleet_sign.py token, then add the printed api_token_hash to this seed node's fleet config.
  5. Push the commit, then run python scripts/fleet_sign.py --group {{ fleet.group or 'baconbbs' }} deploy HEAD --seed http://this-node:8081.
The private key can command every node that trusts it. It stays on the admin machine and is never generated, uploaded, or downloaded by this BBS.

Signed instruction fallback

Routine releases use the deploy command. For recovery, a blob can still be produced on the admin machine with scripts/fleet_sign.py sign <ref>. The blob is not secret: it authorises one commit for one group and cannot be edited without breaking its signature. It is verified here before anything is stored, and rejected if it was not signed by a key this node trusts.
