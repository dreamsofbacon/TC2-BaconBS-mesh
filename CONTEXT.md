# Bacon BBS

Bacon BBS is a bulletin board system serving Meshtastic and MeshCore radio networks, including installations that participate in both.

## Language

**Network parity**:
Equal everyday capability for Meshtastic and MeshCore users: connecting a radio, inspecting its status, managing supported settings, and using public chatter. Parity respects each network's terminology and capabilities.
_Avoid_: 50/50 split (without defining the user capabilities involved)

**Public chatter**:
Conversation heard on radio channels by participating Bacon BBS nodes. Channel names belong to their respective networks; a channel number alone does not identify a shared conversation across networks.

## Example dialogue

**Operator**: I only use MeshCore. Does network parity include me?
**Maintainer**: Yes. Everyday Bacon BBS tasks should work for your network, with its own channel names and supported radio settings.
**Operator**: Does a matching channel number mean Meshtastic users are in the same conversation?
**Maintainer**: No. Public chatter retains the network each conversation belongs to.
